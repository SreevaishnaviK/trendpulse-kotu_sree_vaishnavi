# TrendPulse Project 📊

This project analyzes trending stories using data from the Hacker News API.

##  Features
- Fetches top stories using API
- Cleans and processes data using Pandas
- Performs analysis using NumPy
- Visualizes insights using Matplotlib

##  Project Structure
- task1_data_collection.py → Fetch data from API
- clean_data.py → Clean dataset
- analysis.py → Perform analysis
- task4_visualization.py → Generate charts

##  Outputs
The outputs/ folder contains:
- chart1_top_stories.png
- chart2_categories.png
- chart3_scatter.png
- dashboard.png (bonus)

##  Note
The data is fetched dynamically from the Hacker News API.  
Therefore, results may vary each time the code is executed.

##  Libraries Used
- pandas
- matplotlib
- os

##  How to Run
```bash
python task1_data_collection.py
python clean_data.py
python analysis.py
python task4_visualization.py
